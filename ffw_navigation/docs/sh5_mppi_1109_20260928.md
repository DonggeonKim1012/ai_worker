## Speed and arrival decision

| Setting | Official MPPI | Previous 1109 active default | 1109 MPPI variant |
| --- | --- | --- | --- |
| Omni X/Y maximum speed | 0.55 / 0.55 m/s | 0.35 / 0.35 m/s | 0.35 / 0.35 m/s |
| Curve X/Y maximum speed | 0.50 / 0.25 m/s | No Curve controller | 0.35 / 0.25 m/s |
| Omni/Curve yaw maximum speed | 0.8 / 1.6 rad/s | 0.7 rad/s | 0.7 / 0.7 rad/s |
| MPPI linear / yaw acceleration limits | Omni 3.0 / 3.0; Curve relied on plugin defaults | 0.5 / 1.2 | Both 0.5 / 1.2 |
| Velocity smoother X/Y/yaw maximum | 0.5 / 0.5 / 2.0 | 0.35 / 0.35 / 0.7 | 0.35 / 0.35 / 0.7 |
| Nav2 XY / yaw goal tolerance | 0.20 m / 0.05 rad | 0.025 m / 0.02 rad | 0.025 m / 0.02 rad |
| Smac goal substitution tolerance | 0.5 m | Navfn: 0.0 m | 0.0 m |

The previous 1109 speed cap is the better starting point for the SH5 in its mapped room: it keeps MPPI's modeled commands within the existing smoother limits. The official MPPI speeds and acceleration values would otherwise be clipped downstream, so the controller would optimize trajectories against an overly fast model. The 2-second prediction horizon at 0.35 m/s covers up to 0.70 m of translation, within the 3 m local costmap window.

The previous 2.5 cm Nav2 position tolerance is retained because the 1109 UI checks arrival at about 3 cm. The official 20 cm tolerance could finish an action before that application check passes. The retained 0.02 rad yaw tolerance and stateless XY check continue to demand final alignment. These are estimated-pose thresholds, not measured physical accuracy. The 2026-09-23 stationary AMCL estimate was about 5.7 cm / 7.1 cm XY standard deviation, so a real route may fail to converge to 2.5 cm even when the robot is physically close. This requires a measured driving trial.

The official `plugin_lib_names` includes `nav2_behavior_tree`, which Jazzy reports as a non-plugin library. The 1109 variant lists only `is_path_length_under_plugin`; Jazzy loads built-in Nav2 BT nodes automatically. The official downloaded copy remains unchanged.
